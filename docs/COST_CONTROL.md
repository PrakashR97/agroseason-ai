# Cost control
Database-first lookups; research cache (30d, includes negative results); sketch cache; duplicate job prevention; per-IP limits (120 req/min general, 5 research/hour); daily limits (`SERPER_DAILY_LIMIT`, `OPENAI_DAILY_LIMIT`, default 100); monthly budget (`MONTHLY_BUDGET_USD`, default 10) from logged token usage (`api_usage_log`); max 3 attempts with exponential backoff; 15–30 s HTTP timeouts. When limits are hit, existing verified data is still served and the UI says so. No bulk/automatic research. Measured: one real research job ≈ 2 Serper calls + 2–3 GPT-4o-mini calls ≈ $0.003–0.01. View usage at `/research` or `GET /api/research/usage`.
