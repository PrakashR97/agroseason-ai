# Sketch engine
Cache → Serper image search (restricted to commons.wikimedia.org) → Wikimedia Commons API license lookup (accepts CC0, public domain, CC BY, CC BY-SA only; rejects NC/ND/unknown) → download only from `upload.wikimedia.org` via SSRF-safe client (5 MB cap, content-type check) → Pillow validation (JPEG/PNG/WEBP, 200–8000 px) → OpenCV `pencilSketch` + dodge blend + adaptive-threshold edges + CLAHE + levels → monochrome PNG on white, stored under `MEDIA_DIR/sketches/` → `sketches` row with license, attribution, source URLs.
If no license can be verified, a placeholder is returned and nothing is downloaded; failed lookups are not retried for 7 days. Kinds: produce, plant, seed, seedling, stage. No OpenAI image generation is used. Instructional diagrams (`farming_diagrams`) are only built from verified measurements (table ready; none generated yet).
